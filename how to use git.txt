Step 1 — Create a GitHub account
Go to https://github.com and sign up (free)

Step 2 — Install Git on Windows
Download from https://git-scm.com/download/win and install it

git config user.name "Vineet"
git config user.email "vineet@gmail.com"

Step 3 — Push your website to GitHub
Open Command Prompt inside your website folder and run these commands one by one:
git init
git add .
git commit -m "EKTA Travels website"
Then go to https://github.com/new and create a new repository:

Name: ekta-travels
Keep it Public
Click Create repository

Then run these (replace YOUR_USERNAME with your GitHub username):
git remote add origin https://github.com/YOUR_USERNAME/ekta-travels.git
git branch -M main
git push -u origin main

Step 4 — Deploy on Render.com

Go to https://render.com and sign up with your GitHub account
Click New → Web Service
Click Connect next to your ekta-travels repo
Fill in these settings:

Setting		Value
Name		ekta-travels
Runtime		Node
Build Command	npm install && node build.js
Start Command	node server/index.js

Click Create Web Service
Wait 2–3 minutes

Your website will be live at:
https://ekta-travels.onrender.com


Important — Every time you make changes:
git add .
git commit -m "updated content"
git push


git rm --cached .env → removes file from repo
.gitignore → prevents future commits
git commit --amend → rewrites history (removes secret completely)



Free plan limitations on Render:

Website sleeps after 15 minutes of no traffic
First visit after sleep takes ~30 seconds to wake up
To avoid this, upgrade to Render's $7/month paid plan

Find your computer's IP address — run this in Command Prompt:

Look for IPv4 Address e.g. 192.168.1.5
On your phone browser go to:

  http://192.168.1.5:3000
